# 沉浸动效与 Canvas

在官网、品牌、营销、作品集、创意展示页读取本文件。目标是让页面有记忆点、有生命力，而不是静态排版。**后台、工具、高频工作台和长阅读页不适用**——那里的动效只做状态反馈，不堆砌本文件的沉浸效果。

与防呆门禁配套：所有动效必须可降级、性能可控、不遮挡内容、服务于产品对象。**Canvas/动效是氛围层，不是内容层**；首屏的真实产品对象（截图、商品、作品、数据、媒体）仍然必须是主角，不允许用抽象 Canvas 或循环动画替代真实内容。

## 何时使用

- 官网、品牌页、营销页、作品集、创意展示页：**至少包含一个实质的动效或交互焦点**，不允许整页只有静态排版。
- **用户明确要求「炫酷 / 科技感 / 高级感 / 生动 / 有动效 / 更炫」时，视为沉浸强度要求**：至少组合实现 `2–3` 个动效焦点（如 Canvas/WebGL 背景 + 鼠标/指针交互 + 滚动驱动或入场序列），落在首屏主视觉区；不允许只加一个 hover 微动效敷衍了事。动效要让人一眼感知到页面是"活的"，而不是装饰性细节。
- 后台、工具、编辑器、仪表盘、长阅读文章：不强制，只实现必要的状态反馈（按钮、列表、浮层过渡），不引入大段装饰动画。
- 判断标准：去掉这个动效后页面是否仍然完整？动效是否为产品、品牌或任务服务？如果只是"为了炫"而存在，去掉。

## 技术目录

### Canvas / WebGL 背景

- **流场 / 噪声场粒子**：粒子沿噪声向量场流动，拖出渐隐轨迹（像墨水、数据流），配合鼠标扰动。比「点+连线」有质感，适合科技、机器人、开发者品牌。
- **流动渐变**：低饱和色块缓慢流动（blob），营造品牌氛围。适合消费品牌、创意页。
- **生成式图形**：噪声驱动的有机形状、星云、光斑，用品牌色系。适合品牌首屏。
- **WebGL 着色器**：深色或品牌色系的强视觉背景，需要 GPU；必须提供普通 Canvas 或纯 CSS 降级。
- **交互光照**：canvas 渲染的低饱和径向渐变光斑跟随鼠标，克制优雅，适合材质与氛围。
- **扫描 / 示波器波形**：平滑波形带沿页面扫过，或示波器式实时曲线，配合 HUD/仪器主题。
- 原则：Canvas 是氛围层，置于首屏背景；鼠标/滚动触发粒子的方向、密度或颜色的变化，让背景"活"起来。

### 避免俗套动效（烂大街清单）

以下效果已被大量模板反复使用，**禁止作为默认或主要动效**；如果产品语境确实需要，必须做出明显差异：

- **粒子连线网络**（众多小圆点 + 相互连线 + 连向鼠标）—— 模板感最强，默认禁止
- **随机漂浮的圆形光斑 / 星尘**—— 无视觉意图，禁止默认使用
- **代码雨 / 乱码坠落**—— 廉价科幻感，禁止默认使用
- **无限旋转、抖动、闪烁的装饰元素**—— 干扰阅读，禁止
- **鼠标跟随的彩色拖尾**—— 廉价光标特效，禁止

判断标准：这个效果是否大量模板网站都在用？换成更具体、与产品内容相关的表达（真实数据、产品对象、品牌图形）是否更有记忆点？俗套动效减分，具体动效加分。

### 滚动驱动（Scroll-driven）

- **视差**：背景、图片、装饰元素以不同速度滚动（背景 0.4x、内容 1x、前景 1.2x），制造景深。
- **滚动渐入 + 交错**：区块/列表项进入视口时依次出现（stagger，间隔 60–100ms），不一次性全部淡入。
- **Hero 覆盖过渡**：首屏视差 Hero 随滚动淡出/上移，内容区滚动覆盖上来。
- **滚动进度指示**：顶部或侧边细条显示阅读进度，配合固定导航。
- 实现：用 `IntersectionObserver` 或 GSAP ScrollTrigger 类库触发，**不要用 scroll 事件直接改样式**；触发的 CSS 变换使用 `transform` + `opacity`，利用合成器。

### 鼠标 / 指针交互

- **磁吸按钮**（magnetic button）：鼠标靠近时按钮轻微吸附/位移（≤ 8px），移开后回弹。
- **3D 倾斜卡片**：卡片跟随鼠标倾斜（rotateX/rotateY ≤ 8°），配 `perspective` 与 spotlight 光晕。
- **光标光晕 / 尾迹**：Hero 内光标处一层低饱和光晕跟随，或轻量粒子尾迹。
- **图标与图片 hover**：图标变形（stroke 变化）、卡片内图片轻微位移、文字渐变高亮。
- 触屏端自动退化为无鼠标交互，不残留粘滞状态；动效不影响点击区域。

### 入场与页面转场

- **首屏入场序列**：标题逐行 reveal（clip/translateY + opacity，间隔 80–120ms）、图片 scale-in、CTA 最后出现。
- **数字 / 指标计数**：数字进入视口时从 0 滚动到目标值，配缓动（ease-out，600–1000ms）。
- **区块转场**：区块间的 fade + slide，配合锚点导航；SPA 内页面切换用过渡而非整页刷新。

### 常驻微动效

- **跑马灯**（marquee）：品牌语、logo、特性关键词循环滚动，两端无缝衔接（复制内容实现无缝）。
- **光晕 hover**、渐变背景流动、噪声纹理、闪烁光标、状态点脉冲。
- 长循环动画（≥ 12s）或低频，避免持续干扰；低频不感知的持续动效可用。

## 质量门禁（必须遵守）

1. **可降级**：所有动效在 `prefers-reduced-motion: reduce` 下关闭或转为静止（配合已有全局降级规则）。无 JS 时页面必须完整可用（内容可见、链接可点）。
2. **Canvas 性能**：
   - 使用 `requestAnimationFrame` 驱动，不丢帧不阻塞
   - canvas 尺寸乘以 `devicePixelRatio` 保持清晰，限制到合理上限（如 DPR 2）
   - 页面不可见（`document.hidden`）或元素离开视口时停止渲染
   - 粒子/对象数量受控（常规 ≤ 150），WebGL 只在确有需要时使用
3. **不遮挡内容、不劫持交互**：装饰 Canvas 加 `aria-hidden="true"`；动效元素 `pointer-events` 不阻挡链接和按钮；不劫持滚动、不强制锁定滚动。
4. **时长克制**：入场 300–600ms，hover 150–250ms，滚动驱动 400–800ms；长循环动画 ≥ 12s。不做无限旋转/闪烁干扰。
5. **Canvas 不能替代真实图片**：首屏的产品对象（截图、商品、作品、人物、数据）必须真实存在，Canvas 只做氛围与背景。违反即与「禁止用渐变替代真实图片」同罪。
6. **记忆点而非全部**：一页最多 1–2 个强动效/交互焦点，其余保持克制；动效焦点应服务产品对象或品牌记忆，不与其他动效争抢注意。
7. **交互动效有语义**：鼠标、滚动、点击触发的动效必须与操作意图一致（如点击有反馈、hover 有提示），不与任务冲突。
8. **动效不破坏层级**：动态元素出现后页面在静帧下依然层级清楚、可读、可操作。

## 5 秒自检（官网 / 品牌 / 营销 / 创意页追加）

```
☐ 至少一个实质动效/交互焦点（Canvas / 滚动驱动 / 鼠标交互 / 入场序列 / 数字计数）
☐ 动效非俗套效果（未使用粒子连线网络/漂浮光斑/代码雨等烂大街动效）
☐ 有 prefers-reduced-motion 降级（关闭或静止后页面完整可用）
☐ Canvas 性能合规（rAF / 离屏停止 / devicePixelRatio / 粒子 ≤ 150）
☐ 动效不遮挡内容、不劫持滚动、不阻挡点击（装饰 canvas 已 aria-hidden）
☐ 首屏真实产品对象仍在（Canvas 未替代真实内容）
☐ 动效时长克制（入场 300–600ms，无干扰性长循环）
```
