# 主题色参考

本文件存放用户认可的主题色，用于校准色感和作为选色时的参照。

## 使用规则

- **这是参考色，不是模板**。具体页面的主色仍必须从产品内容推导，或使用用户当前明确提供的色值。
- 参考色的作用是：当模型对"这个产品该用什么色"没有把握时，可以观察这些被认可的颜色在饱和度、明度、色相跨度上的共性，用这个**共性**指导选色，而不是直接复制某个色值。
- 用户提供新色值时追加到对应分类；不因参考色推翻"按产品类型定色相"的规则。

## 共性观察

用户认可的颜色体现了以下稳定规律，选色时参考：

1. **主色默认倾向蓝色系**：认可的三个蓝（#1d74f5 / #0C68E9 / #3b3eff）说明默认主色是蓝；绿色、青色、玫红、橙、红更多作为语义色或点缀，不轻易当作品牌主色。
2. **背景几乎全是极浅色或纯白**：背景层保持高明度（白、浅蓝灰、极浅暖白），不染重色；浅紫蓝渐变可用于特定区块而非整页底色。
3. **文字用经典 5 级灰阶**：#1a1a1a → #bfbfbf 是主文字到禁用的标准递进，层级靠明度拉开，不靠色相。
4. **边框用极浅灰阶**：边框色从 #DCDDE0 到 #F9FAFC 共 8 级，全部是低对比浅灰，用于分隔而非强调；越浅越接近弱分隔线。
5. **深色场景用蓝黑**：#0a0c19 而非纯黑，深色底带轻微蓝色倾向，比 #000000 更柔和。
6. **整体饱和度和明度策略**：彩色集中在主题/语义色上，背景、文字、边框全部无彩色——与 SKILL.md「背景层无彩色、彩色仅小面积点缀」一致。
