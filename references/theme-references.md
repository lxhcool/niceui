# 主题色参考

本文件存放用户认可的主题色，用于校准色感和作为选色时的参照。

## 使用规则

- **这是参考色，不是模板**。具体页面的主色仍必须从产品内容推导，或使用用户当前明确提供的色值。
- 参考色的作用是：当模型对"这个产品该用什么色"没有把握时，可以观察这些被认可的颜色在饱和度、明度、色相跨度上的共性，用这个**共性**指导选色，而不是直接复制某个色值。
- 用户提供新色值时追加到对应分类；不因参考色推翻"按产品类型定色相"的规则。

## 深色模式推导

白天模式切深色时**不能机械反转**（白变黑、黑变白、浅文字变深文字）。从用户的白天色推导深色模式的规则：

**背景与表面层级**（从深到浅递增，方向与浅色模式相反）：
```
--canvas:          #0a0c19   （画布，用用户的深蓝黑，不用纯黑）
--surface:         #141724   （表面，比画布亮一档）
--surface-2:       #1C2030   （次级表面，继续提亮）
--surface-hover:   #232838   （悬停表面）
```

**文字层级**（反转但不用纯白，主文字用近白带轻微冷调）：
```
--text-strong:     #F5F6F8   （标题，不用纯白 #FFF）
--text-primary:    #E4E6EB   （正文）
--text-secondary:  rgba(255,255,255,0.65)   （辅助，用半透明白代替独立灰）
--text-tertiary:   rgba(255,255,255,0.45)   （弱化）
--text-disabled:   rgba(255,255,255,0.25)   （禁用）
```

**边框**（深色模式边框比背景**亮**，与浅色模式方向相反）：
```
--border:          #2A2E3E   （常规边框，比 surface-2 亮）
--border-weak:     #1E2230   （弱分隔，接近表面）
```

**主题色**（深色模式要**提亮**主色，否则对比度不足）：
```
白天 #1d74f5 → 深色模式 #4D8DF5（L 值提高 5-8%）
白天 #0C68E9 → 深色模式 #3D7EF0
```

**语义色**同样提亮，弱背景用低透明度：
```
--danger:  #FF6B6B   （比白天 #FF3030 亮）
--success: #2ED47A
--warning: #FFB648
--danger-bg / success-bg 等用 rgba(主色, 0.12-0.15)
```

**阴影**：深色背景上阴影几乎不可见，层级改用**表面明度差**表达，不用阴影。若需要阴影，用 `rgba(0,0,0,0.3)` 或更深的色值，且只在悬浮层上使用。

**判定规则**：
- 深色画布禁用纯黑 `#000000`（用 `#0a0c19` 这类带轻微色偏的近黑）。
- 深色模式文字主色禁用纯白 `#FFFFFF`（用 `#E4E6EB` 级别，避免刺眼）。
- 边框、表面、文字三者的明度关系必须与浅色模式**反向**（浅色：背景最浅→文字最深；深色：背景最深→文字最亮）。
- 出现机械反转（浅色文字直接变深色文字、白背景直接变黑背景、边框不变）判定为不合格。

## 共性观察

用户认可的颜色体现了以下稳定规律，选色时参考：

1. **主色默认倾向蓝色系**：认可的三个蓝（#1d74f5 / #0C68E9 / #3b3eff）说明默认主色是蓝；绿色、青色、玫红、橙、红更多作为语义色或点缀，不轻易当作品牌主色。
2. **背景几乎全是极浅色或纯白**：背景层保持高明度（白、浅蓝灰、极浅暖白），不染重色；浅紫蓝渐变可用于特定区块而非整页底色。
3. **文字用经典 5 级灰阶**：#1a1a1a → #bfbfbf 是主文字到禁用的标准递进，层级靠明度拉开，不靠色相。
4. **边框用极浅灰阶**：边框色从 #DCDDE0 到 #F9FAFC 共 8 级，全部是低对比浅灰，用于分隔而非强调；越浅越接近弱分隔线。
5. **深色场景用蓝黑**：#0a0c19 而非纯黑，深色底带轻微蓝色倾向，比 #000000 更柔和。
6. **整体饱和度和明度策略**：彩色集中在主题/语义色上，背景、文字、边框全部无彩色——与 SKILL.md「背景层无彩色、彩色仅小面积点缀」一致。
