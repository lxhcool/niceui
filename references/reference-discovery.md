# 参考发现与节奏拆解

在主动寻找设计参考、研究真实产品结构、设计明显动效，或把参考交给 AI 定向生成时读取本文件。目标是解决当前页面的具体问题，不是建立收藏夹或复制获奖网站。

## 先定义要回答的问题

查找前先写出当前缺口，最多选择三项：

- 首屏缺少第一注意目标或产品对象。
- 信息架构、字段、流程或状态不够真实。
- 区段之间缺少推进关系。
- 按钮、导航、选择或提交反馈不清楚。
- 页面缺少一个与产品相关的记忆点。
- 视觉语言与近期页面过于相似。

没有问题定义时不开始漫游式浏览。参考数量不代表结论质量，同一网站的多个页面或连续动效只算一个系统样本。

## 按问题选择来源

以下平台是候选来源，不是必须依次访问的固定清单；平台不可访问时使用同类来源，不伪造观察结果。

| 来源 | 优先解决 | 主要提取 | 不能直接照搬 |
| --- | --- | --- | --- |
| Awwwards、Recent 等展示站 | 品牌官网、作品集、活动页的首屏和记忆点 | 主对象、色块面积、构图偏置、区段节奏、品牌信号 | 获奖站的复杂导航、冗长加载和展示性障碍 |
| MotionSites 等动效案例站 | 进入、滚动、转场和连续叙事 | 触发条件、方向、距离、时长、衔接对象、退出方式 | 每个元素都运动、滚动劫持和无意义视差 |
| Mobbin 等真实产品库 | 后台、工具、商店和移动产品的信息组织 | 字段、状态、操作顺序、错误、空数据、批量动作、移动重排 | 脱离当前平台和业务直接复制组件 |
| Unicorn Studio 等动态场景工具 | 有真实品牌或产品意义的沉浸首屏 | 场景对象、光照、响应输入、性能边界、静态替代 | 用粒子、光晕和循环动画填补内容不足 |
| Refero Styles 等风格索引 | 已确定结构后的视觉语言 | 字体角色、边界、材质、形状、色彩面积、控件语气 | 整页轮廓、固定变量和无语义的风格拼贴 |
| AI Agent | 根据约束生成候选和实现 | 采用项、不采用项、真实内容、交互规格、验证门禁 | 让模型自行平均多个冲突参考 |

展示型页面通常先研究首屏与节奏，再校验真实内容。业务型页面通常先研究真实产品结构，再补视觉与动效。不能为了使用某个平台而颠倒产品任务。

## 拆解静态节奏

不要输出“极简、科技、高级、未来感”等孤立标签。每个入选参考至少记录：

- `首屏抓点`：第一眼看到的真实对象，以及标题、导航和操作如何围绕它排列。
- `阅读推进`：区段顺序、密度变化、对齐轴变化和前后内容的因果关系。
- `视觉语法`：字体角色、形状、边界、材质、色彩面积和图像处理。
- `操作语气`：主要按钮、次级操作、链接、选择和表单如何区分。
- `记忆点`：隐藏 Logo 后仍能识别的一个信号，以及它为什么属于该产品。
- `移动策略`：哪些内容保留、改序、折叠或消失。

将观察标记为“采用”“条件采用”或“不采用”，并写明当前产品依据。不能把互相冲突的参考平均成安全混合物。

## 拆解动态节奏

对视频、交互网站或动效案例按时间关系记录：

- `进入`：首帧是什么，第一对象何时出现，第二层信息如何接入。
- `触发`：页面加载、滚动进度、视口进入、点击、拖动还是系统状态触发。
- `推进`：是揭示新内容、移动同一对象、改变尺度，还是切换叙事阶段。
- `衔接`：哪个对象跨区段保留，前一动作如何解释下一状态。
- `反馈`：hover、focus、press、loading、success 和 error 的视觉差异。
- `退出`：元素如何消失、何时移除、焦点和滚动位置如何恢复。
- `参数`：方向、距离、时长、缓动、延迟与是否可中断。
- `降级`：移动端、低性能设备、无 JavaScript 和 `prefers-reduced-motion` 下如何保持信息与功能。

只记录可观察事实。看不到源代码时，不推断具体库、算法或不可见状态。

## 形成生成简报

交给 AI 或进入编码前，将参考压缩成具体约束：

```text
产品与任务：
首屏主对象：
信息骨架：
采用的参考关系：
不采用的参考特征：
字体 / 边界 / 材质 / 色彩 / 密度：
进入 / 滚动 / 反馈 / 退出：
唯一记忆点：
移动与降级：
真实内容与状态：
验收门禁：
```

至少包含两个“不采用”项，防止生成结果把参考中的显眼特征全部堆进页面。引用具体案例时说明学习的是哪种关系，不能只给链接让 AI 自行猜测。

## 验证参考转译

- 将实现与参考缩略图并排，轮廓、主要色块和对象位置高度一致时重新设计一个主要空间关系。
- 将实现与项目近期页面并排，若字体组合、底色、容器、圆角、眉题、按钮和动效语气再次成套重复，说明参考被旧默认风格吞没。
- 关闭动效后核心任务仍可完成，首屏对象和内容顺序仍然成立。
- 真实内容、性能、响应式和可访问性优先于参考完整度。
