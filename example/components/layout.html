什么是 NiceUI？
NiceUI 是一套面向网页与应用界面的设计、实现和审查工作流，让 AI 模型产出质量稳定的真实界面。
如何安装？
通过 npm 安装：npm install ui-nice-skill，或在 AI 对话中直接引用 SKILL.md。
支持哪些平台？
Web（CSS 原生）、React/Vue/Tailwind、Flutter 各有一套独立实现规则。
